# heroi-das-chamas
Mini jogo de navegação por cômodos desenvolvido exclusivamente com HTML, no qual o jogador assume o papel de um bombeiro e precisa encontrar uma pessoa em uma casa em chamas.

# 👨‍🚒 Herói das Chamas

**Herói das Chamas** é um mini jogo de navegação desenvolvido exclusivamente com HTML. O jogador assume o papel de um bombeiro que precisa entrar em uma casa em chamas, explorar seus cômodos e encontrar a pessoa que ainda está no local.

## 🎯 Objetivo

Encontrar o cômodo de destino e concluir a missão com sucesso, navegando pela casa a partir das passagens disponíveis.

O jogo não fornece dicas sobre a localização da pessoa. Cabe ao jogador explorar os ambientes e escolher seus caminhos.

## 🎮 Como jogar

1. Inicie o jogo na rua, em frente à casa.
2. Escolha uma das entradas disponíveis.
3. Observe o cômodo atual e as passagens disponíveis.
4. Navegue pelos ambientes seguindo as conexões do mapa.
5. Encontre o segundo quarto para concluir a missão.

## 🏠 Mapa da casa

O cenário contém os seguintes espaços:

- Rua
- Sala
- Cozinha
- Corredor
- Primeiro quarto
- Banheiro
- Segundo quarto — destino da missão

A navegação segue as conexões entre os cômodos representadas no mapa do exercício.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura das páginas e navegação entre os cômodos.
- **Links HTML:** implementação das opções de movimentação.

O projeto foi desenvolvido sem CSS e sem JavaScript, como exercício de lógica de navegação e estruturação de páginas HTML.

## 🚀 Como executar

Não é necessário instalar dependências ou configurar um servidor.

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.
4. Comece a jogar!

### Clonar o repositório

```bash
git clone https://github.com/SEU-USUARIO/heroi-das-chamas.git
```

Substitua `SEU-USUARIO` pelo seu nome de usuário do GitHub.

## 📁 Estrutura do projeto

```text
heroi-das-chamas/
├── index.html
├── sala.html
├── cozinha.html
├── corredor.html
├── primeiro_quarto.html
├── banheiro.html
├── segundo_quarto.html
└── README.md
```

Cada arquivo HTML representa uma etapa ou um cômodo do jogo. Os links entre as páginas permitem que o jogador se movimente pela casa.

## 📚 Contexto do projeto

Este projeto foi desenvolvido como exercício prático de HTML, com foco na criação de um mini jogo interativo por meio de páginas conectadas.

A proposta é explorar a navegação entre diferentes ambientes, organizar as opções disponíveis e construir uma experiência simples sem utilizar linguagens de programação adicionais.
